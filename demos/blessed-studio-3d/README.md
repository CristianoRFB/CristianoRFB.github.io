# Blessed Studio 3D — protótipo comercial (DEMO)

Demonstração independente criada a partir de prints públicos do perfil \`@blessedstudio3d\`. **Não é o site oficial da empresa e não processa pedidos reais.**

## Visões
- Cliente: \`#/loja\`
- Gestão fictícia: \`#/painel\`
- Acompanhamento: \`#/acompanhar/EX-202\`

## Fluxo rápido para apresentação
1. Abra a loja, filtre os exemplos, clique em "Personalizar este item".
2. Use informações inteiramente fictícias para criar o pedido de exemplo.
3. Copie o código do acompanhamento.
4. Abra o painel, altere a etapa do pedido e retorne ao acompanhamento.
5. Use "Restaurar exemplo" quando quiser voltar às encomendas iniciais.

**Isolamento:** este protótipo é só HTML/CSS/JS, sem dependências, com dados de teste no localStorage, sem envio de mensagens ou dados, sem login de produção e sem pagamentos. As três visões compartilham estado **somente no mesmo navegador**. O perfil do Instagram é citado como referência pública; fotos, logotipos oficiais e depoimentos não foram copiados.

## Organização
Este arquivo foi adicionado em diretório isolado no repositório de site pessoal. Não altera a página inicial nem produção. Publicação da versão comercial em Worker separado, sem mexer no Pages existente. A eventual fusão à branch principal não faz parte desta demo.
