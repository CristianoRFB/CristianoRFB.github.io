# Mazury Impressão 3D — prévia conceitual

Demonstração independente, não oficial, de catálogo, orçamento sem pagamento e gestão interna simulada para prospecção. Nada é enviado automaticamente para a empresa.

Abra `index.html` em navegador moderno (ou publique como arquivo estático). Visões: `#catalogo`, `#sob-medida`, `#gestao`.

Funcionalidades: busca, filtros, configuração de peças, lista de orçamento, cópia de texto, formulário sob medida, cadastro de solicitação fictícia na gestão, andamento, visibilidade e reset. Persistência apenas local por navegador.

Limitações: imagens ilustradas criadas para o conceito, produtos/preços não oficiais, sem WhatsApp conhecido, sem CRM real, autenticação, armazenamento de pedidos reais ou checkout. Para produção: consentimento, dados do cliente, backend isolado, autenticação e revisão de direitos/portfólio.
