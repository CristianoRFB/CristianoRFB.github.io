Sobre a Matéria

O Projeto Integrador é uma disciplina essencial que desafia os alunos a colocar em prática os conhecimentos adquiridos ao longo do curso. Através do desenvolvimento de um projeto completo, desde a concepção até a entrega, os estudantes vivenciam o ciclo de vida de um produto, aprimorando competências como trabalho em equipe, resolução de problemas e gerenciamento de tarefas.

Tópicos Abordados

GitHub na Prática

Exploramos o uso do GitHub para colaboração em projetos, aprendendo a criar e gerenciar repositórios, além de utilizar recursos como commits, branches e pull requests para controle de versões.

Desenvolvimento do Projeto Integrador

Aplicação dos conhecimentos adquiridos em um projeto real, passando por todas as etapas: levantamento de requisitos, planejamento, execução e apresentação dos resultados.

Integração Multidisciplinar

Trabalho conjunto envolvendo diferentes áreas do conhecimento, promovendo a integração de saberes e a solução de desafios complexos de forma colaborativa.
