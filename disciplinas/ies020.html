Curiosidades

  • O termo "Engenharia de Software" surgiu após a crise do software, destacando a necessidade de processos mais rigorosos.
  • UML é uma linguagem visual que facilita o entendimento entre equipes de desenvolvimento.
  • Metodologias ágeis revolucionaram a entrega de software, tornando o processo mais adaptável.

Sobre a Disciplina

Engenharia de Software trata do desenvolvimento sistemático de sistemas, desde a análise de requisitos até a manutenção. O foco está em criar soluções confiáveis, eficientes e de fácil manutenção, utilizando métodos e ferramentas modernas.

Principais Tópicos

Modelagem de Sistemas

Criação de representações abstratas para visualizar e documentar diferentes aspectos do software.

Diagrama de Classe

Utilização de diagramas UML para ilustrar a estrutura estática do sistema, detalhando classes, atributos e métodos.

Diagrama de Caso de Uso

Representação das interações entre usuários e o sistema, facilitando a identificação de requisitos funcionais.

Processos de Software

Análise de diferentes modelos de desenvolvimento, como cascata, incremental e ágil, avaliando suas aplicações.

Engenharia de Requisitos

Levantamento, análise e validação das necessidades dos usuários para garantir que o sistema atenda às expectativas.

UML

Estudo aprofundado da Unified Modeling Language, padrão para documentação e design de sistemas.

Estudo de Caso

Análise de situações reais, como o caso Boeing, para compreender a importância de processos e testes rigorosos.
