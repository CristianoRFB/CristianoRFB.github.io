Sobre a Matéria

Esta disciplina explora o desenvolvimento de aplicações web e mobile utilizando tecnologias modernas como React.js e Firebase. O foco está em criar interfaces dinâmicas, integradas a serviços de backend, proporcionando experiências completas aos usuários.

Tópicos Abordados

React.js

Estudo da biblioteca React para construção de interfaces baseadas em componentes reutilizáveis.

Estilização e Estrutura de Projetos

Organização de projetos React e aplicação de estilos utilizando diferentes abordagens.

Integração com Firebase

Conexão do front-end com serviços do Firebase, como banco de dados, autenticação e armazenamento.

Desenvolvimento de Telas Práticas

Implementação de telas de e-commerce e outras aplicações, aplicando conceitos de estado e interação com dados externos.
