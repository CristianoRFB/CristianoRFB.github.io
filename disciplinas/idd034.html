Técnicas Avançadas de Banco de Dados Relacional e Não Relacional

Professor: Alexandre Aparecido Bernardes

Curiosidades

  • Bancos NoSQL são cada vez mais usados em aplicações que exigem alta escalabilidade e flexibilidade de dados.
  • Procedures e funções otimizam o desempenho ao executar lógicas diretamente no servidor de banco de dados.
  • O controle de permissões é fundamental para garantir a segurança das informações armazenadas.

Sobre a Matéria

Nesta disciplina, aprofundamos o estudo de bancos de dados, tanto relacionais quanto não relacionais, explorando técnicas de otimização, manipulação avançada de dados e escolha de tecnologias adequadas para diferentes cenários. O objetivo é preparar o aluno para lidar com desafios reais de armazenamento e gerenciamento de dados.

Tópicos Abordados

Introdução ao SSMS e Comandos DDL

Utilização do SQL Server Management Studio para administrar bancos de dados, revisando comandos essenciais para criar e modificar estruturas.

Junções e Estruturas de Tabelas

Estudo das diferentes formas de combinar dados de múltiplas tabelas, compreendendo as aplicações de cada tipo de JOIN.

Subconsultas e Views

Criação de consultas complexas e visualizações personalizadas para facilitar o acesso e a segurança dos dados.

Views Avançadas

Exploração de views com funcionalidades avançadas, como atualização e particionamento, para cenários mais exigentes.

Procedures Armazenadas

Desenvolvimento de procedures para automatizar tarefas e centralizar regras de negócio no banco de dados.

Funções SQL

Implementação de funções para cálculos e retornos personalizados em consultas.

Controle de Acesso (DCL)

Gerenciamento de permissões e segurança, garantindo que apenas usuários autorizados possam acessar ou modificar dados sensíveis.
